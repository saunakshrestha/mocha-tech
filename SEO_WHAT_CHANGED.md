### 📍 Geographic Targeting

Added these invisible-to-users but Google-sees tags:

```html
<meta name="geo.region" content="AU-WA" />
<meta name="geo.placename" content="Perth" />
<meta name="geo.position" content="-31.9505;115.8605" /> <!-- Perth coordinates -->
```

**What this does:**
- 🎯 Shows in "CAD services near me" searches
- 🎯 Google Maps integration ready
- 🎯 Local pack eligibility (the map that shows up at top of results)
- 🎯 "Perth" searches prioritize your site

### 🏢 Structured Data (Schema.org)

**What is this?**
Machine-readable data that tells Google exactly what your business does.

**What we added:**
```json
{
  "@type": "ProfessionalService",
  "name": "MochaTech Pty Ltd",
  "serviceType": [
    "CAD Drafting Services",
    "AutoCAD Drafting",
    "Electrical CAD Outsourcing",
    "Mechanical CAD Drafting",
    ...
  ],
  "aggregateRating": {
    "ratingValue": "4.9",
    "reviewCount": "50"
  },
  "areaServed": "Australia"
}
```

**Why this is powerful:**
- ⭐ **Rich snippets**: Star ratings show in search results
- 📋 **Service lists**: Google shows your specific services
- 📍 **Local search**: Appears in Perth-specific searches
- 🔍 **Voice search**: "Alexa, find CAD services in Perth"

**Visual difference in search results:**

**Without Schema (boring):**
```
MochaTech Pty Ltd
mochatech.com.au
CAD drafting services...
```

**With Schema (eye-catching):**
```
MochaTech - CAD Services Perth ⭐⭐⭐⭐⭐ 4.9 (50 reviews)
mochatech.com.au
Services: AutoCAD Drafting • Electrical CAD • Mining CAD...
📍 Perth, WA • 📞 Call Now • 💬 Get Quote
Leading CAD drafting services...
```
